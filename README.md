# Sem Actualización Modelo Simple

Documentación para ejecutar este proyecto en tu máquina.

## Requisitos Previos

No necesitas instalar nada, el proyecto está construido sobre HTML y JS, utilizando Tensorflow via CDN.

## Instalación

### 1. Clonar el Repositorio

Copia y ejecuta el siguiente comando en tu terminal:

```bash
git clone https://github.com/silveraMatu/sem-actualizacion-modelo-simple.git
```

### 2. Acceder al Directorio del Proyecto

```bash
cd sem-actualizacion-modelo-simple
```

## Ejecución

Para ejecutar el proyecto:

1. Puedes hacer doble click en el archivo `index.html` y automáticamente se abrirá el proyecto en tu navegador predeterminado.

2. Utilizar la extensión `Live Server`.
